# 墨斐单母图、单帧生成提示词（中文）

## 母图

每一次生成都只上传这一张图，作为唯一参考图：

`mofei_idle_f01.png`

不要上传图集、旧状态图或上一帧。每次只生成一张独立的 1024x1024 PNG，不生成拼图、九宫格、角色设定图或多帧画面。

## 固定提示词

每次请求都先完整复制这一段，再追加下方对应的“逐帧指令”。

```text
以我上传的墨斐母图作为唯一且不可变的角色参考。只生成一张独立的 1024x1024 正方形 PNG。纯白背景。不要文字、logo、界面、标题、字幕、投影底座、场景、其他角色、拼图、联系表或多帧布局。

角色模型不可改变：严格保持母图相同的正面居中镜头、镜头距离、留白、冰蓝色半透明水平玻璃胶囊、深海军蓝圆角面罩、两只竖直发光白眼、四个青蓝色扫描角框，以及一条青蓝色轨道环。

固定几何：胶囊宽度为画布宽度的 76%，高度为画布高度的 36%，长宽比例 2.1:1；面罩宽度为胶囊宽度的 58%，高度为胶囊高度的 68%；每只眼睛宽度为面罩宽度的 9%，高度为面罩高度的 42%，双眼间距为面罩宽度的 20%。四个角框的尺寸、线宽和位置完全固定。不得裁掉轨道环。

严格保留母图的透明玻璃材质、深蓝面罩、冰蓝高光、青蓝角框颜色、干净柔和的 3D 插画风格、居中构图和正面朝向。除了本次逐帧指令明确说明的表情或动作外，其他任何元素都不许修改。

禁止：改变身体轮廓、比例、眼睛数量、眼睛位置、面罩形状、角框位置、轨道位置、透视、镜头角度、裁切和整体配色；禁止手脚、耳朵、嘴巴、头发、衣服、饰品、道具、背景物体、对话气泡、文字、图标、第二条轨道、扁平矢量风、像素风、日漫重设计。
```

## 使用方式

1. 上传且只上传 `mofei_idle_f01.png`。
2. 粘贴“固定提示词”。
3. 再粘贴一个“逐帧指令”。
4. 每次只保存输出的一张图片，并采用指令中的文件名。
5. 下一帧仍从同一张母图开始，不以刚生成的图片作为新参考图。

建议播放速度：紧急 120ms/帧；提醒、即将到期、专注、完成 140ms/帧；待命、确认、休息 160ms/帧。
