# 墨斐外部截屏与过期状态修复设计

## 目标

修复外部悬浮墨斐截屏时进入随手办主页面、同时出现两个墨斐的问题；精简外部能力环；让过期事项退出墨斐状态竞争。

## 外部能力环

外部能力环仅保留“截屏”“通知草稿”“当前事项”。“截屏”统一执行当前屏幕截取、事项识别、预览和确认保存。外部能力环移除“最近截图”和“能力设置”；应用内能力环保持现有能力。

## 截屏任务栈与悬浮窗生命周期

屏幕捕获授权 Activity 使用独立且不进入最近任务列表的透明任务栈，避免激活随手办主 Activity。它必须保留到系统授权回调，不能使用会提前销毁 Activity 的 `noHistory`；取消或失败时显式移除临时任务。启动捕获前移除系统悬浮墨斐；成功时将恢复责任交给截图预览页。预览结束前不恢复系统悬浮墨斐，避免它与应用内墨斐同时出现。

## 过期事项选择

DDL 已过期且仍未完成的事项保留在卡片数据中，但不再参与墨斐状态竞争。状态解析器只在未完成、未归档且未过期的事项中沿用现有优先级和截止时间排序；若没有有效事项，则继续解析草稿、工作流和待命状态。

## 验证

- JVM 测试验证外部动作目录只包含三个指定动作。
- JVM 测试验证过期事项被跳过，并由剩余事项中优先级最高者接管状态。
- Android 清单测试或静态校验验证捕获 Activity 的独立任务栈属性。
- 运行相关单元测试、完整 Android 单元测试和 Debug APK 构建。
