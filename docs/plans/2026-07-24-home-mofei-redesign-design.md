# 随手办首页莫斐视觉重构设计

## 目标

在不改变首页信息架构、业务数据与交互入口的前提下，将莫斐系统性融入顶部主视觉、行动状态和今日关注三个区域，并统一卡片层级、间距、颜色与底部导航视觉。

## 已确认方案

采用 image2 基于用户提供的莫斐母图生成三张场景化透明素材：

- `hero`：轻微倾斜、明亮友好，作为顶部蓝色渐变卡片的主视觉。
- `status`：更紧凑、眼神偏向数据区，作为行动状态卡片右上角的辅助角色。
- `empty`：专注表情、与半透明候选卡形成前后关系，作为今日关注空状态视觉。

三张素材必须保留横向冰蓝胶囊、深蓝面罩、两只竖眼、四个扫描角标和轨道环；禁止手、脚、机械臂、人形肩膀或躯干。生成源使用纯色键控背景，落库前移除背景并检查透明边缘。

## 页面结构

### 顶部主视觉

保持“随手办”、副标题、说明文字、四步流程和导入截图按钮。卡片使用蓝色渐变与克制光晕；文字和操作位于左侧，hero 莫斐从右下角探出。窄屏下收紧文字宽度、步骤间距和莫斐尺寸，不隐藏角色。

### 行动状态

继续从 `AppUiState` 计算进行中、待确认、有时间和提醒数量。三个指标等宽排列，使用蓝、橙、青蓝的低透明背景。status 莫斐位于标题行右上方，不覆盖指标。最近处理状态和识别方式保持动态显示。

### 今日关注

标题行继续显示动态事项数量。空状态采用左侧文案与按钮、右侧 empty 莫斐及抽象候选卡的构图；存在事项时继续复用当前行动卡列表和“查看全部行动卡”入口。

### 底部导航

保留五个导航项、当前路由和点击行为。只调整容器背景、激活态圆角底板、图标/文字颜色和安全区留白，不改变导航枚举或路由路径。

## 组件与数据流

- `HomeScreen` 继续接收现有 `AppUiState` 和回调，不引入新的状态管理。
- 新增首页专用 `HomeMofei` 组件，按 `hero/status/empty` 变体选择资源、尺寸、语义描述和轻量浮动幅度。
- `state.settings.reduceMascotMotion` 控制非必要浮动动画；关闭动画时固定首帧。
- 导入截图按钮继续打开现有来源选择对话框，再调用相册或相机回调。

## 响应式与可访问性

- 使用 `BoxWithConstraints`、权重、尺寸区间和最小间距适配 320–430dp。
- 所有主要操作继续使用真实 Compose `Button`；装饰性图片不重复朗读，承载品牌语义的莫斐提供内容描述。
- 页面底部保留足够滚动留白，避免被固定导航栏遮挡。
- 不新增大型依赖，不使用整页位图，不把中文文案写入图片。

## 验证

- 编译 Android debug APK。
- 运行 Android JVM 单元测试。
- 检查三张 PNG 的尺寸、alpha 通道、透明边角和角色覆盖比例。
- 在模拟器或连接设备上分别截取首页，检查 320–430dp 无横向溢出、文字遮挡和按钮失效。
- 复核 Git 差异只包含首页、首页专用素材、必要测试和设计文档。
